# RPG Client Demo

一个基于 Unity / Tuanjie 的第三人称 RPG 客户端练习项目。项目包含主菜单入口、异步加载界面和 RPG 玩法场景，并围绕一个完整的玩法闭环展开：玩家与 NPC 对话接取任务，击杀石头人推进任务进度，怪物死亡后掉落药水，玩家拾取药水进入背包，并可在背包界面中使用药水恢复生命值。

项目重点展示 Unity 客户端常见模块的实现能力，包括角色控制、战斗判定、敌人 AI、掉落拾取、背包数据、任务状态、UI 面板刷新和场景异步加载。

## 项目概览

- 引擎版本：Unity 2022.3.61t9 / Tuanjie 1.6.8
- 开发语言：C#
- 主要场景：
  - `Assets/Scenes/menuScene.scene`：主菜单页面与加载界面，可点击开始进入玩法场景
  - `Assets/Scenes/Scene_A.unity`：RPG 玩法演示场景
- 核心脚本目录：`Assets/Scripts`

## 功能展示

- 第三人称角色控制：键盘移动、鼠标控制视角、角色朝向同步、鼠标锁定与解锁。
- 战斗系统：普通攻击、技能攻击、扇形近战判定、飞行特效命中判定。
- 敌人 AI：敌人生成、发现玩家后追击、近距离攻击、脱离范围后回到出生点。
- 生命与反馈：玩家血量、敌人受击、伤害飘字、死亡与复活、血条刷新。
- 掉落与背包：怪物死亡掉落药水，玩家触碰掉落物后加入背包，背包显示数量，点击药水消耗并恢复生命值。
- NPC 与任务：靠近 NPC 显示交互提示，按 `F` 弹出对话框，接受后进入任务系统，击杀目标敌人后更新进度并显示完成状态。
- UI 系统：角色血条、背包按钮与背包面板、任务按钮与任务面板、NPC 交互提示、对话框显示与隐藏。
- 主菜单加载：从菜单页面点击开始后进入加载界面，并异步切换到 RPG 玩法场景。

## 操作说明

- `WASD`：移动角色
- 鼠标移动：控制视角与角色朝向
- 鼠标左键：普通攻击
- 鼠标右键：技能攻击
- `F`：靠近 NPC 时打开对话并接取任务
- `B`：打开或关闭背包界面
- `I`：打开或关闭任务界面
- `Left Alt`：切换鼠标锁定状态
- 背包中点击药水格子：消耗 1 个药水并恢复生命值

## 玩法闭环

1. 从主菜单页面点击开始，经过加载界面进入 RPG 玩法场景。
2. 进入玩法场景后，玩家可以移动、旋转视角并攻击敌人。
3. 靠近 NPC 时出现交互提示，按 `F` 打开对话框。
4. 点击接受后任务进入任务系统，任务面板显示任务名、描述、进度和状态。
5. 击杀石头人后，任务进度从 `0 / 2` 更新到 `1 / 2`、`2 / 2`。
6. 怪物死亡时掉落药水，玩家触碰药水后加入背包。
7. 打开背包界面可以看到药水数量，点击药水后恢复生命值并减少数量。
8. 任务目标达成后，任务状态显示为已完成。

## 数据配置

- `Assets/Resources/item.xml`：物品配置，目前包含小型生命药水，定义物品 id、名称、描述、类型和恢复量。
- `Assets/Resources/quest.xml`：任务配置，目前包含击杀两个石头人的主线任务，定义任务 id、描述、目标敌人 id、目标数量和奖励字段。

物品与任务配置和运行时状态分离：配置文件描述静态数据，`InventoryManager` 与 `QuestManager` 维护运行时数量、进度和状态。

## 客户端开发能力体现

- 能实现从主菜单、异步加载、输入、战斗、AI、掉落、背包、任务到 UI 反馈的基础 RPG 客户端闭环。
- 使用 Collider、Prefab、Animator、Resources、Canvas UI、Button 事件等 Unity 常用机制完成玩法系统。
- 将物品和任务的配置数据与运行时状态拆分，便于后续扩展更多物品和任务。
- 背包与任务 UI 通过 Manager 层读取状态并刷新显示，避免 UI 直接管理核心玩法数据。
- 对重复触发、鼠标锁定、UI 面板显示、伤害飘字朝向等实际调试问题做了处理。
